# 國小教學互動網頁提示詞產生器 (Interactive-Web-new)

設計：陳佳釧老師  
專為國小教師打造的 AI 互動網頁提示詞（Prompt）快速生成工具。

## 功能特色

1. **學科與年段自訂**：國語、數學、社會、自然、英語、藝文、綜合、健體等學科，涵蓋低中高年級。
2. **多樣化互動機制**：單選測驗、拖曳配對、翻牌記憶、填空拼字、語音朗讀、分類整理、探索地圖等。
3. **客製教學輔助**：即時回饋音效、計時挑戰、計分獎勵、重試機制。
4. **視覺設計風格**：莫蘭迪溫暖色系、活潑童趣風、星空宇宙風等多款版面選擇。
5. **一鍵複製與匯出**：生成結構化 Prompt，支援一鍵複製與下載 `.txt` 檔案，可直接貼給 Claude / ChatGPT / Gemini 產出單一 HTML 互動教材。
